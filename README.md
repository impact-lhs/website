# IMPACT holding page

A plain static website for GitHub Pages. No build process or framework is required.

## Publish

Upload the following to the root of the `impact-lhs/website` repository:

- `index.html`
- `styles.css`
- `script.js`
- the complete `assets` folder

Commit the files to `main`. GitHub Pages will redeploy automatically.

## Editing later

- Page wording and section order: `index.html`
- Colours, spacing and responsive layout: `styles.css`
- Logo artwork: `assets/impact-logo.svg`
- Current brand navy: `#102A43`

## Before using the contact link

Create or forward `contact@impact-lhs.com`, or replace the address in `index.html`.
